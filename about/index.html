关于

我是 sitxiaochen，这个站点用来存放平时的运维记录、工具折腾笔记和 AI 相关的实践文档。

技术栈

  • Astro —— 静态站点生成，默认零 JS，按需加载交互
  • TypeScript —— 内容 schema 与构建脚本全类型化
  • Tailwind CSS —— 原子化样式，暗色优先的设计语言
  • SQLite + Drizzle —— 构建期数据快照，汇总文章、标签与站内链接
  • Pagefind —— 构建时生成静态全文索引，纯前端检索
  • GitHub Pages + Actions —— 推送到 main 后自动构建发布

内容与版权
